# 功能说明

1. 拖拽 功能：
    1. 鼠标左键点击拖动，宠物跟随鼠标移动
    2. 右键，或者系统托盘右键，可以 开启/关闭 拖拽功能
2. 抛掷 功能：
    1. 鼠标左键释放时，宠物抛出，遵循鼠标释放速度自由落体
    2. 状态栏位置修正：如果宠物不在状态栏范围内，自动调整到状态栏位置
    3. 右键，或者系统托盘右键，可以 开启/关闭 抛掷功能
3. 鼠标跟随功能：
    1. 宠物会自动跟随鼠标移动，保持与鼠标的距离和角度
    2. 仅按住左边Ctrl时，临时 强制退出跟随
    3. 右键，或者系统托盘右键，可以 开启/关闭 鼠标跟随功能
    4. 设置页，可以设置 跟随速度
4. 鼠标穿透功能：
    1. 宠物会自动穿透鼠标点击事件，不会遮挡鼠标点击
    2. 仅按住左边Ctrl时，临时强制不穿透，鼠标点击强制传递给宠物
    3. 右键，或者系统托盘右键，可以 开启/关闭 鼠标穿透功能
5. 放大功能：
    1. 到达指定时间，宠物会自动放大
    2. 右键，或者系统托盘右键，可以 设置 当前的 放大状态（准备放大/放大中
    3. 设置页，可以设置：
        1. 放大 功能是否启用
        2. 放大的等待时间，和 放大的比例
6. 设置页：
    1. 右键，或者系统托盘右键，可以 打开 设置页窗口
    2. 屏幕循环 功能：如左边消失，右边出现
    3. 宠物的 默认 放大比例
