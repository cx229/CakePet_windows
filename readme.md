# 功能说明

程序运行后，可在电脑右侧小图标托盘（有可能被隐藏了）查看图标

强烈推荐 右键 程序图标，打开设置，设置页有每个功能的简单说明

1. 单击拖动 功能：
    1. 鼠标左键点击拖动，宠物跟随鼠标移动
2. 重力抛掷 功能：
    1. 鼠标左键释放时，宠物抛出，遵循鼠标释放速度自由落体
    2. 状态栏位置修正：如果宠物不在状态栏范围内，自动调整到状态栏位置
    3. 反弹 模式
        4. 宠物会在碰到屏幕边界时，触发反弹，改变移动方向
        5. 可以设置反弹系数，反弹系数越大，反弹损失的能量越小
        6. 可以指定上下左右，那些需要反弹
3. 鼠标跟随 功能：
    1. 宠物会自动跟随鼠标移动，保持与鼠标的距离和角度
    2. 仅按住左边Ctrl时，临时 强制退出跟随
    4. 可以设置 跟随速度
4. 鼠标穿透 功能：
    1. 宠物会自动穿透鼠标点击事件，不会遮挡鼠标点击
    2. 仅按住左边Ctrl时，临时强制不穿透，鼠标点击强制传递给宠物
5. 放大 功能：
    1. 到达指定时间，宠物会自动放大
    2. 右键 可以 设置 当前的 放大状态（准备放大/放大中)
    3. 可以设置：
        1. 放大 功能是否启用
        2. 放大的等待时间，和 放大的比例
3. 托盘消息 功能
    1. 在系统托盘区域显示消息
    2. 可以设置是否显示打字速度
    3. 可以设置消息位置：托盘区左侧，或者任务栏左侧
    4. 可以设置消息的颜色
    5. 可以设置消息窗口的边距，即位置的偏移量
6. 其他
    7. 可以设置 基本缩放比例
    8. 可以设置 日志记录级别
